# Password Generator & Your Own Module

## Project Description

This project demonstrates how to use Python modules and functions. It includes a password generator that uses Python's built-in `random` and `string` modules, as well as a custom function that can generate passwords of different lengths.

## Files

* `password_generator.py` — Contains the `make_password()` function.
* `helpers.py` — Contains helper code for the project.
* `main.py` — Imports the password generator and creates passwords.
* `README.md` — Provides information about the project.

## Concepts Practiced

* Importing Python modules using `import`
* Using the built-in `random` module
* Using the built-in `string` module
* Creating and using functions
* Using default function arguments
* Importing a function from another Python file
* Generating random passwords
* Checking password length with `len()`

## How to Run

Open the terminal in the project folder and run:

```bash
python main.py
```

The program generates:

1. A default password with 8 characters.
2. A password with 12 characters.

The passwords and their lengths are displayed on the screen.

## Example Output

```text
Default password: aB7xP2mQ
Length: 8
12-character password: K8mP2xQ7aB4z
Length: 12
```

The actual passwords will be different each time because they are generated randomly.
